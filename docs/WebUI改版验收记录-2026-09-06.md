## 实现

1. 明亮粉蓝配色、圆角消息与推荐卡片、侧栏历史搜索、独立资料库及领域筛选、手机抽屉导航；登录与管理端统一。主题图为本地图片，不代表具体学校。
2. Markdown 渲染标题、强调、列表、GFM 表格、代码块与引用；禁用原始 HTML、远程图片请求和非 HTTP(S) 普通链接。已验证的 `[[EVn]]` 标记转换为引用按钮，代码中的标记保持字面量。
3. 原文依据默认收起为卡片，点击后展示引文、行号、真实 PDF 页码（有数据时）和完整原文入口；原文弹窗继续使用鉴权读取、下载，支持 Escape 关闭和键盘焦点返回。
4. 工作步骤由实际后端操作触发：分析问题与范围、生成查询向量、关键词与向量检索、读取上下文、版本查询、整理依据生成回答、核验引用。只展示发生的步骤，失败明确标注未完成，不提供虚构百分比或模型内部思维。
5. 步骤与流式回答一起持久化；生成期间展开步骤，完成后折叠。保留已有范围确认、部分回答保存、取消与中断恢复。

## 启动

从当前仓库根目录执行 `pwsh -NoProfile -File ./scripts/start-local.ps1`。已有 8011 服务时直接访问；端口占用会明确报错，可用 `-Port 8012` 更换。前台启动后 `Ctrl+C` 停止。服务数据保留在本 worktree 忽略目录。

配置优先从当前 `.env` 读取，缺失则只读加载主仓库 `.env`；可用 `-ConfigFile` 显式指定，Python 可通过 `-Python` 指定。任何密钥均未复制到本 worktree 或受控文件。
