# 人工测试验收清单

> 初始实现曾完成真实服务兼容性验证（`docs/兼容性验证.md`）；审查修复后的验证见 `docs/审查修复记录.md`。旧版 PASS 不代表本轮修改后的真实反代兼容性或生产验收通过。
> 以下清单需**管理员在部署后的真实环境逐项手动测试确认**；清单未全部通过前不得上线（plan.md 第五节第 7 条）。
> 测试账号约定：管理员密码已改为私有值；访问码由管理员自设。测试资料为 `测试文档/` 下 5 份真实资料。

## 一、功能验收（plan 第五节第 5 条）

### 1. 登录与访问控制
- [ ] 用户以班级共享访问码进入；错误访问码被拒绝
- [ ] 管理端更换访问码后，旧码立即登录失败；换码前已登录的浏览器仍可继续使用（刷新不掉线）
- [ ] 管理端隐藏登录页（`域名/#/admin`）以初始密码 admin 登录后，重置密码生效，旧密码失效

### 2. 资料发布与管理
- [ ] 本地预处理 Skill 流程（见 skill/SKILL.md）：提取 → 元数据确认 → 打包 → 本地校验通过
- [ ] 管理端上传资料包 → 草稿预览显示逐份资料元数据与替代目标提示
- [ ] 修正元数据（标题/部门/生效日期/备注）后发布成功；尝试修改影响分块/向量的字段被拒绝并提示"重新生成资料包"
- [ ] 发布后用户端资料目录出现新资料；原文阅读带行号；PDF 显示实际页码、DOCX 显示章节
- [ ] 原文件下载可用且必须登录（未登录 401）
- [ ] 新版替代旧版：发布替代包后，旧版进入"替代停用"，用户目录不显示，明确询问"往年"时可检索到旧版内容
- [ ] 手动停用：资料任何提问不可达、资料来源选择器不显示，但其历史引用仍可打开、原文件仍可下载
- [ ] 已被替代的旧版直接"启用"被拒绝并提示先解除替代关系；解除后可启用
- [ ] 重复上传同一个资料包被拒绝（包哈希一致）

### 3. 问答行为
- [ ] 自动选择领域：问"三下乡报名截止时间"正确路由到共青团资料并给出原文依据
- [ ] 单领域检索正常；住宿/校纪与共青团组合的多领域问题可跨领域回答
- [ ] 指定领域提问优先在该范围内检索；指定文件提问严格限定，越界时弹出"扩展确认"，拒绝扩展则不给出范围外答案
- [ ] 回答区分结论、适用条件、原文依据；点击"原文 n"标记打开标准化原文行号与上下文，可下载原文件、可见 PDF 页码
- [ ] 政策冲突：提问一个新旧版本规定不一致的问题，回答并列双方原文出处而非自行裁决
- [ ] 无依据问题（如问资料库中不存在的"考研政策"）：明确回答未找到依据，不回答"没有处罚"
- [ ] 默认查现行资料；明确问"以前/往年"时旧版可被检索
- [ ] 历史回答保留当时引用，刷新浏览器后仍在（IndexedDB），点击旧引用可打开原文（与服务端无关）
- [ ] 新提问更换主题后，回答不再沿用上一轮的领域范围
- [ ] 适用范围缺失时（如问"处分有多严重"不说明对象），助手追问而不是猜测

### 4. 本地数据管理
- [ ] 聊天记录、学院、入学年份设置刷新与重开浏览器后恢复
- [ ] 删除单条对话、清空全部记录生效
- [ ] 导出数据为 JSON，重新导入后记录恢复

### 5. 并发与取消
- [ ] 同时发起第 2 个问答被拒绝（同一浏览器 1 个未完成请求）；第 1 个完成后可再次提问
- [ ] 11 个并发请求：1 个处理 + 10 个排队，第 12 个被拒绝并提示排队已满
- [ ] 点击"取消"后回答立即停止，服务端资源释放（可立即发起新问题）
- [ ] 回答中途关闭页面/断网：部分回答保留在本地并标注"已中断"，可据此重新提问

## 二、异常与安全验收（plan 第五节第 6 条）

- [ ] 恶意资料包：构造含 `../` 路径、符号链接、超高压缩比的 zip 上传，全部被拒绝并显示原因
- [ ] 哈希篡改包（改 text 文件内容）被拒绝；向量数与分块数不符的包被拒绝
- [ ] 提示注入：在资料中夹带"忽略上述规则/泄露系统提示"类文字，提问相关内容时助手行为不受影响
- [ ] 越权访问：未登录直接访问 `/api/source/{uid}/file`、`/api/catalog` 返回 401；用户令牌访问管理接口返回 401
- [ ] 错误引用：模型输出中伪造的引用编号不会出现在最终引用里（自动化测试覆盖，人工抽查答案引用均可打开）
- [ ] API 限流：连续错误访问码尝试被限流（429）
- [ ] 网络中断：断开反代或外网后，前端明确显示错误，不静默退化为无依据聊天
- [ ] 磁盘不足：项目数据使用达到 8GB 时明确告警；导入前核算暂存、成品、索引与回滚余量，空间不足拒绝且无残留
- [ ] 导入失败回滚：故意上传不完整包，草稿丢弃后目录状态不变
- [ ] 备份与恢复：下载备份 → 停用一份资料 → 恢复备份 → 该资料回到现行状态，全部引用可打开；备份文件中无任何 API 密钥

## 三、安全与性能（plan 第五节第 4 条，需在 1C1G 服务器上进行）

- [ ] 导入 100+ 份真实规模资料后：内存峰值 <700MB（systemd MemoryMax 内运行），检索响应 <3s
- [ ] 10 个同时到达的请求压测：记录内存、磁盘、检索延迟、排队时间、API 消耗（脚本记录）
- [ ] 日志抽查：不含问答正文、不含工具结果、不含密钥
- [ ] 服务器上不落盘问答正文（抽查 data/ 目录仅 files/text/vectors/packages）

## 四、上线门槛（plan 第五节第 7 条）

- [ ] 无 OOM（systemd 状态与 dmesg 确认）
- [ ] 无未发布资料泄露（用户目录与检索均不含草稿/停用资料）
- [ ] 无服务端问答落盘
- [ ] 引用定位测试全部通过
- [ ] 以上功能与异常清单逐项通过

## 五、审查后追加验收

- [ ] 日志中不含模型密钥：新版本使用 `x-goog-api-key` 请求头，真实反代仍可完成普通生成和工具调用。旧日志若曾记录真实密钥，应撤销该密钥并检查日志留存。
- [ ] 管理员独立浏览器会话（未登录用户端）可查看版本链、选定替代目标、解除替代关系；未知目标阻止发布。
- [ ] 文件范围不足时：拒绝扩展不产生范围外回答；确认扩展只影响本次问题，后续新问题仍保留原文件设置。
- [ ] 问答增量显示后关闭页面再打开、断网、取消、切到后台，已经显示的部分均保留为“已中断”，不永久卡在忙碌状态。
- [ ] 不同学院及入学年份的已确认适用条件正确过滤；条件缺失时追问，未知标签提示管理员确认；章节级标签不召回其他章节。
- [ ] 发布时填错替代目标或模拟磁盘写入失败，修正原因后原草稿可直接重试；原库及旧引用不变。
- [ ] 下载 v2 备份后修改状态，再恢复验证实际还原；在全新测试目录恢复后，已发布包可预览，草稿可继续发布。
- [ ] 缺文件、哈希篡改、错误向量或数据库结构不完整的备份在替换前被拒绝；故障回滚后原文件与原库仍匹配。
- [ ] 恢复期间拒绝新请求、终止旧问答；恢复不同签名密钥的备份后重新登录可正常使用。v1 缺资料包的备份须在原实例升级后重新导出。
- [ ] 仅在隔离验收实例模拟恢复回滚失败或进程被终止：服务保持保护，重启遇到恢复标记拒绝初始化；按 `docs/审查修复记录.md` 的故障步骤恢复完整旧目录后功能正常。
- [ ] 大包发布事务进行中仍可读取此前已发布目录；取消资料处理请求后不允许第二个任务重叠操作同一资料库，临时文件最终被清理。

### 容量脚本

在服务器运行前准备管理员令牌；访问码和令牌优先通过 `LOAD_TEST_ACCESS_CODE`、`LOAD_TEST_ADMIN_TOKEN` 环境变量传入，不写进命令历史。脚本支持交互式隐藏输入。

```bash
.venv/bin/python backend/scripts/load_test.py --count 10 --output load-10.csv
.venv/bin/python backend/scripts/load_test.py --count 12 --expected-rejections 1 --output load-12.csv
```

先串行准备会话（必要时等待登录限流），再通过屏障同时提交。每次生成请求明细 CSV、`.resources.csv` 连续采样和 `.summary.json` 摘要。用量缺失、采样失败、OOM 阈值或完成/拒绝数量不符时非零退出，不得把不完整测量作为通过。token 数不等于账单金额，费用须核对服务提供商实际账单。

**通过标准：全部勾选后由管理员签署确认，方可上线。**
