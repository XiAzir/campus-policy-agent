## 零、本机验收准备（Windows PowerShell 7）

以下命令都在仓库根目录执行。项目已有 `backend/data`，因此**不要直接使用 README 中的普通启动命令做破坏性验收**。本机人工验收固定使用忽略目录 `.local-acceptance/data`；备份、停用、恢复、改密码等操作只影响该目录。

### 1. 自动化基线

```powershell
.venv/Scripts/python.exe -m pytest -q
Push-Location frontend
npm.cmd test
npm.cmd run build
npm.cmd run test:e2e
Pop-Location
```

- [x] 后端显示 `79 passed`（允许出现 Starlette/AnyIO 弃用警告）
- [x] 前端组件显示 `12 passed`，生产构建成功，Chromium 显示 `4 passed`

### 2. 真实服务兼容性（会调用外部模型，可能产生费用）

确认根目录 `.env` 中是可用于测试的真实配置，并确认 `测试资料包-2026-09.zip` 存在。两个脚本均不使用正式 `backend/data`；兼容性报告默认写入忽略目录 `.local-acceptance/`，端到端脚本使用执行结束即删除的临时资料库。

```powershell
.venv/Scripts/python.exe backend/scripts/verify_compat.py
.venv/Scripts/python.exe backend/scripts/e2e_real.py
```

- [x] 兼容性脚本全部 PASS，`.local-acceptance/兼容性验证.md` 不含密钥、问题正文或上游错误正文
- [x] 真实端到端脚本全部 PASS，并确认 `backend/data` 的修改时间、资料和访问码均未被改变

### 3. 启动持久的隔离验收实例

先在当前 PowerShell 窗口设置进程环境，再启动服务。不要关闭此窗口；人工验收结束用 `Ctrl+C` 停止。浏览器访问用户端 `http://127.0.0.1:8010/`，管理端 `http://127.0.0.1:8010/#/admin`。

```powershell
$root = (Get-Location).Path
$env:DATA_DIR = Join-Path $root '.local-acceptance/data'
$env:INITIAL_ADMIN_PASSWORD = 'admin'
.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8010 --workers 1
```

- [x] 启动日志中的数据目录指向 `.local-acceptance/data`，而不是 `backend/data`
- [x] 以初始管理员密码 `admin` 登录隔离实例，设置仅用于本次验收的访问码

下文第一、二、五节可在该隔离实例执行。涉及恶意包、恢复故障、断网和密码修改的项目不得针对已有正式数据目录操作。本机验收通过后保留 `.local-acceptance/` 供复查；需要重做时先停止服务，再删除该忽略目录重新开始。

## 二、异常与安全验收（plan 第五节第 6 条）

- [ ] 恶意资料包：构造含 `../` 路径、符号链接、超高压缩比的 zip 上传，全部被拒绝并显示原因
- [ ] 哈希篡改包（改 text 文件内容）被拒绝；向量数与分块数不符的包被拒绝
- [ ] 提示注入：在资料中夹带"忽略上述规则/泄露系统提示"类文字，提问相关内容时助手行为不受影响
- [x] 越权访问：未登录直接访问 `/api/source/{uid}/file`、`/api/catalog` 返回 401；用户令牌访问管理接口返回 401
- [ ] 错误引用：模型输出中伪造的引用编号不会出现在最终引用里（自动化测试覆盖，人工抽查答案引用均可打开）
- [x] API 限流：连续错误访问码尝试被限流（429）
- [ ] 网络中断：断开反代或外网后，前端明确显示错误，不静默退化为无依据聊天
- [ ] 磁盘不足：项目数据使用达到 8GB 时明确告警；导入前核算暂存、成品、索引与回滚余量，空间不足拒绝且无残留
- [ ] 导入失败回滚：故意上传不完整包，草稿丢弃后目录状态不变
- [x] 备份与恢复：下载备份 → 停用一份资料 → 恢复备份 → 5 份资料回到现行状态；备份不含配置中的两项 API 密钥

### 容量脚本

以下命令是 Ubuntu 服务器命令，**本机阶段不执行**。服务器运行前准备管理员令牌；访问码和令牌优先通过 `LOAD_TEST_ACCESS_CODE`、`LOAD_TEST_ADMIN_TOKEN` 环境变量传入，不写进命令历史。脚本支持交互式隐藏输入。

```bash
.venv/bin/python backend/scripts/load_test.py --count 10 --output load-10.csv
.venv/bin/python backend/scripts/load_test.py --count 12 --expected-rejections 1 --output load-12.csv
```

先串行准备会话（必要时等待登录限流），再通过屏障同时提交。每次生成请求明细 CSV、`.resources.csv` 连续采样和 `.summary.json` 摘要。用量缺失、采样失败、OOM 阈值或完成/拒绝数量不符时非零退出，不得把不完整测量作为通过。token 数不等于账单金额，费用须核对服务提供商实际账单。
